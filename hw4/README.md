## Bytecode Verifier
Run main.cpp to start the program. Program takes a file path with bytecode as an argument.

### Output
Program runs verifier and interpreter on the bytecode file. Then prints the time taken for each step.

### Time
* Verification: 53 microseconds
* Interpreter without checks: 128.727 seconds
* Interpreter with checks: 151.34 seconds
* lamac -i: 352.46 seconds
* lamac -s: 102.44 seconds
